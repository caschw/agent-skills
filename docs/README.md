# Documentation

Each skill in [`skills/`](../skills) has a matching folder here with documentation for
both humans and agents. Runtime instructions stay in the skill folder (`SKILL.md`,
`references/`, `assets/`); these docs explain design, usage, and examples in depth and
are not installed with the skill.

| Skill | Documentation |
| --- | --- |
| `domain-collaboration` | [domain-collaboration/](domain-collaboration/README.md) |

New skills must add a folder with at least a `README.md`; the validator enforces it.
